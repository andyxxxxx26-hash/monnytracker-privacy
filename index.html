Política de Privacidad de MonnyTracker

Última actualización: Octubre 2026

1. Información que recopilamos

MonnyTracker accede a los datos de notificaciones y correos electrónicos de Gmail únicamente con el propósito explícito de identificar y registrar transacciones financieras personales de servicios como Yape y Plin.

2. Uso de la información

Toda la información procesada se utiliza de manera estrictamente local en el dispositivo del usuario para generar reportes financieros personales. MonnyTracker no vende, alquila, transfiere ni comparte datos personales o bancarios con terceros.

3. Almacenamiento y Seguridad

Los datos de las transacciones se almacenan localmente en el dispositivo del usuario utilizando bases de datos seguras. El usuario conserva el control total sobre sus datos y puede eliminarlos en cualquier momento borrando la aplicación.

4. Cumplimiento de Políticas de Google

El uso de la información recibida de las APIs de Google cumple con la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de Uso Limitado (Limited Use).
